# 💗 Lip Gloss Studio

### A little world of lip care, glossy colors, and endless creativity.

**Lip Gloss Studio** is a relaxing, interactive lip-care and makeup sandbox game. Experiment with different lip balms, glosses, lipsticks, and cosmetic treatments while creating your own perfect lip looks.

Inspired by Y2K beauty aesthetics, the game combines glossy pink visuals, cute cosmetic packaging, satisfying application mechanics, and relaxing ASMR-inspired sounds.

## ✨ Features

- 💄 **Lip Care:** Clean, exfoliate, moisturize, and prepare your lips.
- 🍓 **Lip Balm Collection:** Explore cherry, strawberry, vanilla, honey, mint, tinted balms, and more.
- 💋 **Makeup Studio:** Experiment with lipsticks, liners, tints, glosses, and glitter.
- 🧴 **Different Applicators:** Use balm sticks, squeeze tubes, brushes, gloss wands, and more.
- 🎨 **Freehand Application:** Drag products across the lips and watch the coverage develop.
- ✨ **Satisfying Effects:** Glossy reflections, glitter particles, smooth blending, and cosmetic animations.
- 🎧 **ASMR Sounds:** Enjoy relaxing cosmetic application sounds and background music.
- 🪞 **Creative Sandbox:** Experiment freely without timers, scores, or pressure.
- 💾 **Save Your Looks:** Keep your favorite cosmetic combinations.

## 🎀 Aesthetic

A nostalgic Y2K-inspired beauty studio featuring:

## 🎮 Gameplay

Choose your favorite cosmetic product, select an applicator, and start experimenting.

Apply multiple products, combine different textures, adjust colors, and create unique looks. There are no rules or time limits. Just relax and enjoy the process.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/lip-gloss-studio.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

### Deploy with GitHub Pages

1. Upload the project to a GitHub repository.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` directory.
5. Save and wait for deployment.

Your game will be available as a public website.
